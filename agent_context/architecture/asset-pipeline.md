# Asset pipeline (`game-assets/`)

Turns a hand-written description of each Element into a voxel model for Godot.
Terms (Element, Spec, Part, Layout, Grid, State, Tier): [CONTEXT.md](../../CONTEXT.md).

```
game-assets/<tier>/<id>-<Name>/spec.md      what the Parts are (hand-owned, ≤40 lines)
                              /layout.toml  where Parts sit (hand-owned)
        │  uv run voxel-sdk check  → validate + ASCII preview (no Blender)
        │  uv run voxel-sdk build  → build.py (generated, git-ignored)
        ▼
Blender (blender-voxel-py skill) → .blend / .glb → dusk-till-dawn/levels, assets
```

- Tiers: `t1-tiny` … `t6-building`. Index of all Elements: `game-assets/INDEX.md`
  (generated by `voxel-sdk index`, never edited by hand).
- No `layout.toml` = hand-written Element: its tracked `build.py` is the only source.
  Never run plain `build` on it.
- States (`Name_State`, e.g. `ACUnit_On`) are separate models swapped in the engine.
- Design and scope: `docs/adr/0001-generate-build-py-from-spec-and-layout.md`.

## SDK (`game-assets/sdk/`, Python, run with `uv`)

| Command (from `game-assets/sdk/`) | Does |
|---|---|
| `uv run voxel-sdk check <dir> [--full] [--state <Name>]` | Validate; exit 1 on errors |
| `uv run voxel-sdk build <dir> [--standalone]` | Write `build.py` |
| `uv run voxel-sdk index [--check]` | Regenerate `INDEX.md` |
| `uv run pytest` | SDK tests |

Layout keys: `game-assets/sdk/README.md`.
Examples: `t2-small/t2-17-Monitor`, `t2-small/t2-26-PDU` (States), `t1-tiny/t1-06-Mug` (round).

**Before touching any Element:** [../assets/README.md](../assets/README.md).
