# Idea: upgrades, shop and customisation

v1 shop sells only the counter-upgrades for the 8 incidents ([game-v1.md](../game-v1.md#9-nights-difficulty-and-the-shop)). The full upgrade tree below is for later.

## Upgrade tree

| Area | Chain |
|---|---|
| DDoS | CDN shield → auto rate limiting |
| Dependencies | vulnerability scanner → auto-updates |
| Certificates | auto-renewal |
| Logins | 2FA → hardware keys |
| Power | more panels → bigger battery → generator |
| Fire | extinguisher → sprinklers → gas suppression |
| Cooling | second AC unit |
| Data | RAID → backups → off-site backups |

Idea: after protecting the system you unlock better protections or better infrastructure.

## Points and customisation

- Points each night buy boosts or **character customisation** (cosmetic, parked for M3).

## Upgrades from outdoor areas

- Dock: spare parts stock, trusted supplier contract, serial number scanner, security camera, delivery drone pad (late game) → [delivery-dock.md](delivery-dock.md)
- Generator: monthly auto-test, fuel level sensor, block heater, second generator (late game), smart load shedding → [generator-yard.md](generator-yard.md)
- Outdoor time savers: tablet, golf cart, drone, security cameras → [outdoor-areas.md](outdoor-areas.md)

## Balancing

Use Machinations (machinations.io) to simulate the economy when balancing the shop (milestone M3).
