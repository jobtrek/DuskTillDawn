# Idea: game modes and progression

Not in v1. See [game-v1.md](../game-v1.md#11-parked-ideas-not-in-v1).

## Infinite mode (M2)
Just play and survive as long as possible until the system goes down. Spawn rate keeps rising. Score = in-game hours survived.

## Sleep / day cycle (M3)
You sleep at night and work during the day. If a major incident happens at night, you wake up and solve it. v1 replaces this with the shop screen.

## Daytime maintenance (M3)
See [daytime-maintenance.md](daytime-maintenance.md).

## Bigger companies and more levels (M4)
More electricity and servers, harder levels. Needs the base game balanced first.

## Lose conditions (original idea)
SLA credits and uptime must stay above a threshold. If they drop too low, or the system is down too long, the company goes bankrupt. v1 uses SLA = 0 only.

## Computer apps (original idea)
- Email: latest tech news
- Grafana-style dashboard: server and app status, latency
- Hints icon (the original idea was a ChatGPT icon; v1 uses our own AI helper character)
